# Claude Code 中转站切换器图标方案

| 编号 | 图标 | 侧重点 |
| --- | --- | --- |
| 01 | 双向切换 | 最初使用的图标，表示中转站切换 |
| 02 | 节点路由 | 当前选定图标，一个入口连向多个中转站 |
| 03 | 终端入口 | 在项目文件夹中打开 Claude Code |
| 04 | 模型切换 | 在多个模型之间选择 |

每款提供 512×512 透明 PNG 和包含 16、24、32、48、64、128、256 像素的 Windows ICO。`preview.png` 是四款图标的对照图。当前桌面快捷方式使用暮紫香槟配色的 02 节点路由。
